# 📚 HSC Science Complete Revision Tracker

A responsive, web-based study management dashboard designed to help Bangladeshi Higher Secondary Certificate (HSC) Science students track, organize, and optimize their preparation across the full National Curriculum and Textbook Board (NCTB) syllabus.

🔗 **Live Interactive Demo:** [https://mahbubahmedsadi10.github.io/HSC-Tracker/]([https://mahbubahmedsadi10.github.io/HSC-Tracker/])

---

## 🌟 Overview & Problem Statement

Preparing for the HSC examination in Bangladesh requires mastering eight comprehensive papers across Physics, Chemistry, Higher Mathematics, and Biology. Students often struggle with tracking syllabus completion systematically across dozens of chapters and revised exam guidelines.

This project solves that issue by offering a clean, tabbed dashboard where students can visually monitor their preparation percentage in real time, set granular study milestones, and add custom short-syllabus or admission-specific topics without needing a backend server or login process.

---

## ✨ Key Features

* **Complete NCTB Syllabus Pre-loaded:** Covers all chapters across all 8 Science papers:
  * **Physics:** 1st & 2nd Paper
  * **Chemistry:** 1st & 2nd Paper
  * **Higher Mathematics:** 1st & 2nd Paper
  * **Biology:** 1st Paper (Botany) & 2nd Paper (Zoology)
* **Tabbed Navigation Architecture:** Organized into 8 clickable subject slides for reduced cognitive load and seamless navigation.
* **Dual-Layer Progress Analytics:** Real-time percentage bars tracking both overall syllabus completion and individual paper progress.
* **Persistent Local Storage (`localStorage`):** User checkmarks and custom topics automatically persist across browser sessions without collecting personal data.
* **Dynamic Topic Expansion:** Allows users to dynamically inject custom sub-chapters, practical topics, or admission test notes.
* **Mobile-Responsive UI:** Built with modern CSS custom properties and flexible layouts for phone, tablet, and desktop viewing.

---

## 🛠️ Technical Stack & Architecture

* **Frontend:** HTML5, CSS3 (CSS Variables, Flexbox, Keyframe Animations)
* **Logic & Data Control:** Native JavaScript (ES6+)
* **Data Persistence:** Web Storage API (`window.localStorage`)
* **Deployment & Hosting:** GitHub Pages (Static Web Hosting)
